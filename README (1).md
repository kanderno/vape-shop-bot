# RazkiWaka — Telegram-бот для приема заказов

Повторяет сценарий со скринов:
1. `/start` → приветствие + кнопки **«🔥 Прайс / Вкусы»** и **«🛍 Оформить заказ»**
2. Прайс — показывает список категорий (Waka10000 Pro, Waka10000 старый) с ценами и вкусами
3. Оформить заказ — пошагово спрашивает: вкус → количество → телефон → адрес/способ получения → подтверждение
4. После подтверждения заявка отправляется администратору(ам) в личные сообщения

## Установка

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.

3. Узнайте свой Telegram ID через [@userinfobot](https://t.me/userinfobot).

4. Откройте `config.py` и заполните:
   - `BOT_TOKEN` — токен от BotFather (или задайте переменную окружения `BOT_TOKEN`)
   - `ADMIN_CHAT_IDS` — список ID администраторов, куда будут приходить заказы
   - `PRICE_LIST` — при необходимости отредактируйте вкусы и цены
   - `ADMIN_CHAT_IDS` в списке `[123456789]` — замените на реальные ID

5. Запустите бота:
   ```bash
   python bot.py
   ```
   либо с токеном через переменную окружения:
   ```bash
   BOT_TOKEN=ваш_токен python bot.py
   ```

## Как редактировать прайс

Все вкусы и цены лежат в `config.py` в переменной `PRICE_LIST` — это список категорий, у каждой есть `title` (заголовок с ценой) и `flavors` (список вкусов). Просто добавляйте/удаляйте строки — бот сам пересоберет текст прайса.

## Важно

- Администратор должен один раз написать своему боту `/start` в личку, иначе бот не сможет присылать ему уведомления (ограничение Telegram — бот не может первым написать пользователю).
- Для продакшена (постоянная работа 24/7) бот нужно разместить на сервере или в облаке (VPS, Railway, Render и т.п.) и запускать как фоновый процесс/сервис.
- Продажа вейп-продукции обычно регулируется законом по возрасту покупателя и локальным нормам — при желании можно добавить в `/start` подтверждение "18+" перед показом меню.
